# ועד הבית – עמוד אחד

עמוד HTML יחיד (`index.html`) שקורא את כל הנתונים מ-`data.json`.

## מה יש בעמוד
- **טבלת תשלומים** – 19 דירות × 12 חודשים: ✓ שולם, ✗ לא שולם (רק חודשים שכבר עברו), סכום ששולם וחוב לכל דירה.
- **דוח הכנסות והוצאות** – סיכום, רשימת הוצאות, והכנסות מול הוצאות לפי חודש.
- **קבלות** – העלאת תמונות (נשמרות בדפדפן בלבד), וקבלות קבועות מהתיקייה `receipts/`.
- **תשלום** – כפתורי ביט ופייבוקס.

## עדכון נתונים (`data.json`)
- `monthlyFee` – דמי ועד חודשיים.
- `apartments[].paidMonths` – מספרי החודשים ששולמו (1–12). למשל `[1, 2, 3]`.
- `expenses` / `otherIncome` – תאריך בפורמט `YYYY-MM-DD`, תיאור, סכום.
- `receipts` – קבלות שכל הדיירים יראו: `{ "title": "...", "date": "2026-03-05", "file": "receipts/elevator.jpg" }`.
- `payment` – `bitPhone` (מספר לביט), `bitLink` (קישור לביט אם יש), `payboxLink` (קישור לקבוצת פייבוקס – מתוך האפליקציה: "הזמנת חברים לקבוצה").

## הרצה
`fetch` לא עובד כשפותחים את הקובץ ישירות (`file://`) – אז העמוד יציע לבחור את `data.json` ידנית.
הכי פשוט: להפעיל GitHub Pages על הריפו, או מקומית: `python3 -m http.server` ולפתוח http://localhost:8000
